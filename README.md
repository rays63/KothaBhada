# KothaBhada

A Flutter application for comprehensive rental property management, designed to streamline the administration of houses, rooms, tenants, utilities, and payments.

## Features

### In Scope
- **House and Room Management**: Organize and track properties and their individual rooms.
- **Tenant Management**: Maintain tenant information, leases, and contact details.
- **Electricity Consumption Tracking and History**: Monitor and record electricity usage with historical data.
- **Internet Cost Management per Room**: Track and allocate internet expenses for each room.
- **Utility Cost Tracking**: Manage costs for water, garbage, and other utilities.
- **Payment Tracking**: Record and monitor rent payments plus utility charges.
- **Dashboard with Summary Insights**: View key metrics and summaries at a glance.
- **Reminder System**: Local notifications for important dates and tasks.
- **Meter Image Capture and Storage**: Capture and store images of utility meters.
- **Local Data Persistence**: Secure storage using SQLite database.
- **Manual Backup and Restore**: Export and import data for backup purposes.

## Getting Started

### Prerequisites

- Flutter SDK (^3.11.4)
- Dart SDK

### Installation

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd kothabhada
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

For help getting started with Flutter development, view the [online documentation](https://docs.flutter.dev/), which offers tutorials, samples, guidance on mobile development, and a full API reference.
